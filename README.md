# iConic

Iconic Tecnologia — toda a sua casa em uma tela. App instalável (PWA).

Endereço: https://leandropor-glitch.github.io/iconic/

- `index.html`: app (abas Cenas, Cômodos, Controles).
- `comodos.json`: mapa padrão de cômodos, cores e controles (botão → cena).
- `sw.js`: service worker (abre rápido e funciona com a lista guardada).
